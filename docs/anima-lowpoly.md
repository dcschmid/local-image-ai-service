# Retired Anima Low Poly profiles

Low Poly PS1 / PSX and Low Poly Style are no longer part of the service catalog,
installer, Studio or CLI. Low-poly generation now uses [MOSS presets](moss-lowpoly.md)
and the [Blender reference workflow](blender-references.md).

Anima Aesthetic remains installed for anime and illustration. Shared base weights,
original Downloads files and existing gallery images are retained. Historical
images can be viewed and exported; their removed model settings cannot be loaded.

The [old adapter report](anima-lowpoly-test-report.md) records historical measurements.
